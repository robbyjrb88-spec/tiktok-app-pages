Privacy Policy

Last updated: October 3, 2026

Robby DJ Tools is a personal, single-user application built and operated by Robby for his own use only. It is not available to the public and does not collect, process, or store data on behalf of any other person.

What this app does

This app connects to Robby's own TikTok account via TikTok's official API to post content and view basic performance statistics (views, likes, comments, shares) for videos Robby has posted himself.

What data is accessed

  • Basic TikTok account info for the authenticated user (Robby's own account only).
  • A list of Robby's own posted videos and their public engagement counts.

How data is stored

OAuth access and refresh tokens are stored locally and securely on Robby's own computer (in the macOS Keychain). No TikTok data is sold, shared, or transferred to any third party. No data from any other TikTok user is ever accessed.
